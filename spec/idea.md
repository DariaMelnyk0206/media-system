\# Initial Project Idea



The idea of the project is to create an information system for organizing and storing consumed media content. The user will be able to add individual media items, such as books, movies, TV series, articles, podcasts, videos, and other types of content, and store basic information about them.



A key feature of the system will be the ability to organize different media items around user-defined topics. For example, a user could create a topic such as “Space Exploration” and add a book, a documentary, an article, and a podcast related to this topic. The same media item can belong to multiple topics. For example, a science fiction movie could be associated with topics such as “Space”, “Science”, and “Future Technologies”.



The relationship between media items and topics should work in both directions. A user should be able to open a topic and see all media items associated with it, as well as open an individual book, movie, or article and see which topics it belongs to.



The user will also be able to create personal notes for each media item. These notes can contain thoughts after reading or watching something, interesting facts, conclusions, questions, or any other information the user wants to keep together with the media item.



Overall, the system is intended to provide a personal space for keeping consumed media content, organizing it around the user’s interests, and preserving personal notes about it.
